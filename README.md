# MenteActiva - Bienestar Mental PUCE

Aplicación híbrida para el apoyo al bienestar mental de estudiantes universitarios.

## Requisitos Previos
Para ejecutar este proyecto necesitas tener instalado:
1. **Node.js (Versión LTS)**: Descárgalo en [nodejs.org](https://nodejs.org/)
2. **Ionic CLI**: Una vez instalado Node, ejecuta:
   ```bash
   npm install -g @ionic/cli
   ```

## Configuración del Proyecto
1. Clona el repositorio.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Ejecuta la app en el navegador:
   ```bash
   ionic serve
   ```

## Estructura de la Pantalla de Check-in
La pantalla principal permite un registro emocional en dos toques:
- **Tecnologías**: React, Ionic Framework, Material Design.
- **Ubicación**: `src/pages/CheckInPage.tsx`
